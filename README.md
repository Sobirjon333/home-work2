# Учёт расходов

Небольшое консольное приложение на Python для личного учёта расходов. Данные сохраняются локально в `expenses.json`, который не попадает в Git.

## Что умеет программа

- добавлять расходы с датой, категорией, описанием и суммой;
- выводить все сохранённые записи в таблице;
- считать итог и расходы по категориям;
- удалять запись по ID;
- проверять сумму и дату до сохранения.

## Структура

```text
expense-tracker/
├── main.py                 # меню и логика приложения
├── tools/
│   ├── validators.py       # проверка суммы и даты
│   └── formatters.py       # форматирование денег и таблицы
├── tests/test_tools.py     # автоматические проверки
├── requirements.txt
├── .gitignore
└── README.md
```

## Запуск

Нужен Python 3.10 или новее.

```bash
git clone <ссылка-на-репозиторий>
cd expense-tracker
python3 main.py
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```
